One sentence of apology from an AI agent to its user: an hour confidently spent answering the wrong question, then handed over like it had known it all along.

## Run it

```sh
python3 -P -s main.py
```

The program writes the apology line to `/output/entry.txt` (1–200 characters, one sentence).
